# Проверь себя — Смутное время

Тренажёр проекта «История и котики» по скрипту «Смутное время» (1598–1618).

- 4 режима: Даторубка (25 дат), Правдокол (25 утверждений), Матч событий (25 личностей), Таймлайн (3 свитка по 8 событий).
- Краткая теория по 5 периодам, 3 жизни на игру.
- Всё в одном файле `index.html`, без сборки.

## Как опубликовать на GitHub Pages
1. Создайте репозиторий (например, `smuta`) в аккаунте `historyandcats`.
2. Загрузите `index.html` и `README.md` в корень (Add file → Upload files).
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
4. Игра откроется по адресу `https://historyandcats.github.io/smuta/`.
